# winopen — 윈도우 공유 경로를 맥 파인더에서 바로 열기

메신저·메일로 받은 `\\서버\공유\폴더` 형식의 윈도우 경로를 macOS 파인더에서 바로 엽니다.
공유가 마운트돼 있지 않으면 먼저 마운트하고, 그 안의 폴더를 엽니다.

- **메뉴바 앱** `윈도우경로열기.app` — 메뉴바 아이콘에서
  - 클립보드 경로 열기 (⌘O) · 경로 입력해서 열기 (⌘L)
  - 파인더에서 선택한 항목의 윈도우 경로 복사 (⌘C) — 거꾸로 윈도우 사용자에게 보낼 때
  - 즐겨찾기 (⌘1~⌘9) · 추가(클립보드 경로 / 지금 열린 파인더 폴더)
  - 즐겨찾기 관리 — 이름 바꾸기 · 경로 수정 · 맨 위로/위로/아래로/맨 아래로 · 삭제
  - 파인더 새 탭으로 열기(기본 켬) · 로그인 시 자동 실행
- **CLI** `winopen` — `winopen '\\fileserver\share\folder'`, 인자 없이 실행하면 클립보드 경로를 엽니다.

지원 입력: `\\host\share\...` · `//host/share/...` · `smb://host/share/...`(퍼센트 인코딩 해석). 앞뒤 공백과 바깥을 감싼 따옴표 한 쌍은 무시합니다. 공유 밖으로 나가는 `..` 는 거부합니다.
폴더는 열고, 파일은 파인더에서 선택해서 보여 줍니다. 없는 경로면 남아 있는 가장 가까운 상위 폴더를 엽니다.

## 설치

macOS 13 이상, Xcode 명령줄 도구(`swiftc`)가 필요합니다.

```bash
git clone https://github.com/hada0127/winopen.git
cd winopen
./build.sh          # /Applications/윈도우경로열기.app 설치 후 실행, ~/bin 이 있으면 winopen CLI 도 복사
```

### 권한

- **새 탭으로 열기**: 파인더에는 새 탭을 여는 API 가 없어 ⌘T 를 보낸 뒤 그 탭의 위치를 바꿉니다.
  처음 쓰면 「System Events 제어」(자동화)와 「손쉬운 사용」 권한을 묻습니다. 권한이 없거나 파인더 창이 하나도 없으면 새 창으로 엽니다.
  CLI 에서는 `WINOPEN_TAB=0` 으로 끌 수 있습니다(터미널 앱에 권한 필요).
- **윈도우 경로 복사 / 지금 열린 폴더 추가**: 「Finder 제어」(자동화) 권한을 묻습니다.
- 시스템 설정 → 개인정보 보호 및 보안 → 자동화 / 손쉬운 사용 에서 바꿀 수 있습니다.
  ad-hoc 서명이라 다시 빌드하면 권한을 한 번 더 물을 수 있습니다.

## 설정 파일

`~/Library/Application Support/WinOpen/` 아래에 둡니다.

| 파일 | 형식 | 용도 |
|---|---|---|
| `favorites.tsv` | `이름<탭>경로` 한 줄씩. `#` 주석, 빈 줄은 메뉴 구분선 | 즐겨찾기 (메뉴에서 편집 가능, 이름은 `#` 으로 시작할 수 없음) |
| `hosts.tsv` | `호스트<탭>IP` 한 줄씩 | 호스트명으로 마운트가 안 될 때(-5014 등) IP 로 바꿔 마운트 |

`hosts.tsv` 위치는 환경변수 `WINOPEN_HOSTS` 로 바꿀 수 있습니다.
메뉴바 앱으로 연 기록·오류는 `~/Library/Logs/WinOpen.log` 에 남습니다(CLI 는 터미널에 출력).
